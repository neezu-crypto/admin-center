# SOOP 홍보글 작성 보조 (실험용)

관리 센터의 `스트리머별 홍보글 바로가기` 세션에서 선택한 스트리머의 제목·본문·HTML을 SOOP 게시글 작성 화면으로 전달하는 Chromium Manifest V3 확장 프로그램입니다.

## 현재 범위

- 관리자 센터 홍보 목록의 `글쓰기 열기`를 누르면 해당 스트리머의 홍보글을 생성해 SOOP 글쓰기 화면에 전달합니다.
- `홍보글 생성` 패널에서 내용을 확인·수정한 뒤 패널 안의 `글쓰기 열기`를 눌러도 작동합니다.
- SOOP 글쓰기 페이지의 제목과 본문 편집 영역에 생성된 내용을 입력합니다.
- 본문은 SOOP 편집기의 붙여넣기/입력 이벤트로 전달합니다. 화면 DOM만 직접 바꾸는 방식은 사용하지 않으며, 입력 결과가 글자처럼 보이거나 편집기에서 비어 있다고 판단되면 성공으로 표시하지 않습니다.
- 게시 및 임시저장 버튼은 누르지 않습니다. 관리자가 직접 게시한 뒤 SOOP 주소가 `/station/{방송국}/post/write/{게시판}`에서 `/station/{방송국}/post/{게시글}`로 바뀌고, 표시된 글의 제목과 게임 링크가 작성 내용과 일치할 때만 관리 센터에 홍보 완료를 표시합니다. 본문 첫 문장을 수정해도 게임 링크가 남아 있으면 확인할 수 있으며, 게시글이 새 탭에서 열려도 같은 방송국과 글 내용으로 작성 건을 찾아 처리합니다.
- 게시 버튼 클릭만으로 완료 처리하지 않습니다. 게시 화면 전환이나 제목·본문 확인이 실패하면 자동 체크하지 않으며, 관리 센터 탭을 닫았거나 로그인 세션이 만료된 경우도 저장되지 않을 수 있습니다.
- 전송 내용은 확장 프로그램의 세션 저장소에 탭별로 잠시 보관하고, 해당 SOOP 탭에서 한 번 가져온 뒤 삭제합니다.
- 접근 권한은 관리자 센터와 SOOP 게시글 작성 URL에 한정됩니다.

## 설치 및 시험

아직 확장 프로그램 저장소에 등록된 제품이 아닙니다. 웨일의 확장 프로그램 관리 화면에서 개발자 모드를 켜고 이 폴더를 압축해제된 확장 프로그램으로 불러와야 합니다. 외부 소스의 확장 프로그램을 로드하기 전에는 manifest의 권한과 대상 URL을 확인하세요.

첫 시험은 본인 방송국의 지정된 글쓰기 화면에서 제목, 본문, 이미지 표시만 확인하고 게시/임시저장은 직접 누르지 않는 절차로 진행합니다.

코드가 갱신되면 `whale://extensions`에서 개발자 모드의 새로고침 버튼을 눌러 확장 프로그램을 다시 불러온 뒤 시험합니다. 제목·본문이 편집기에 들어간 것을 확인한 다음 게시 버튼은 직접 누르세요. 게시가 완료되면 상세 페이지로 이동하고, 관리 센터 목록의 완료 표시를 확인합니다.
