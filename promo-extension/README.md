# SOOP 홍보글 작성 보조 (실험용)

관리 센터의 `스트리머별 홍보글 바로가기` 세션에서 선택한 스트리머의 제목·본문·HTML을 SOOP 게시글 작성 화면으로 전달하는 Chromium Manifest V3 확장 프로그램입니다.

## 현재 범위

- 관리자 센터 홍보 목록의 `글쓰기 열기`를 누르면 해당 스트리머의 홍보글을 생성해 SOOP 글쓰기 화면에 전달합니다.
- `홍보글 생성` 패널에서 내용을 확인·수정한 뒤 패널 안의 `글쓰기 열기`를 눌러도 작동합니다.
- SOOP 글쓰기 페이지의 제목과 본문 편집 영역에 생성된 내용을 입력합니다.
- 게시 및 임시저장 버튼은 누르지 않습니다.
- 전송 내용은 확장 프로그램의 세션 저장소에 탭별로 잠시 보관하고, 해당 SOOP 탭에서 한 번 가져온 뒤 삭제합니다.
- 접근 권한은 관리자 센터와 SOOP 게시글 작성 URL에 한정됩니다.

## 설치 및 시험

아직 확장 프로그램 저장소에 등록된 제품이 아닙니다. 웨일의 확장 프로그램 관리 화면에서 개발자 모드를 켜고 이 폴더를 압축해제된 확장 프로그램으로 불러와야 합니다. 외부 소스의 확장 프로그램을 로드하기 전에는 manifest의 권한과 대상 URL을 확인하세요.

첫 시험은 본인 방송국의 지정된 글쓰기 화면에서 제목, 본문, 이미지 표시만 확인하고 게시/임시저장은 직접 누르지 않는 절차로 진행합니다.
