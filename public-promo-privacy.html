2. 처리하는 정보와 목적

검색어는 검색 결과를 만들기 위해 요청 처리 중 서버에 전달되지만 통계 데이터베이스에는 저장하지 않습니다. 페이지 통계에는 검색 실행 횟수만 집계됩니다. SOOP 비밀번호와 카드·결제정보는 페이지가 수집하지 않습니다. 주소 수정과 홍보글 내용은 브라우저에만 저장되며 페이지 운영 서버로 전송되지 않습니다. 이용자가 백업 파일로 내보낸 경우 파일은 이용자가 지정한 위치에 저장됩니다.

3. 보유 및 이용 기간

  • 광고 신청 정보는 신청 검토·후원 확인·게재 및 문의 대응을 위해 보관합니다. 현재 신청 레코드에 자동 삭제 기간이 설정되어 있지 않으므로, 운영 목적이 끝난 뒤 운영자가 삭제하기 전까지 남을 수 있습니다.
  • 통계는 날짜별 합계로 저장됩니다. 현재 별도의 자동 삭제 기간을 두지 않아 운영자가 정리할 때까지 보관될 수 있습니다. 이용자를 직접 식별하는 계정 ID나 검색어는 이 통계에 포함하지 않습니다.
  • 요청 제한 해시는 시간 구간이 바뀌면 다음 요청에서 새 구간 값으로 갱신됩니다. 데이터에는 만료 예정 시각이 기록되지만 현재 자동 청소 작업은 확인되지 않아, 요청이 다시 없으면 이전 해시 레코드가 더 오래 남을 수 있습니다.
  • 브라우저 저장 정보는 이용자가 사이트 데이터를 지우거나 페이지의 백업·복원 기능을 사용해 관리할 수 있습니다. 브라우저 저장소가 초기화되면 복구할 수 없을 수 있습니다.

4. 처리 위탁 및 국외 처리

페이지는 정적 웹 호스팅에 GitHub Pages를 사용하고, 목록·통계·요청 제한·광고 신청 처리를 위해 Google Firebase(Cloud Functions, Realtime Database, Authentication)를 사용합니다. 관련 데이터는 Firebase의 미국 us-central1 리전에서 처리·저장될 수 있습니다. 광고 프로필 이미지는 SOOP 이미지 서버에서 불러오며, 방송국 이동·별풍선 후원은 이용자가 SOOP에서 직접 진행합니다.

각 제공자는 호스팅·인증·저장·요청 처리를 수행하는 서비스 제공자로서 정보를 처리할 수 있습니다. Google Firebase는 Firebase 개인정보 보호 안내, GitHub는 GitHub 개인정보 처리방침을 참고해 주세요. 외부 서비스가 자체적으로 수집하는 접속 로그·쿠키 등은 각 제공자의 정책과 설정을 따릅니다.

5. 이용자의 권리와 행사 방법

이용자는 자신과 관련된 광고 신청 정보에 대해 열람·정정·삭제·처리정지를 요청할 수 있습니다. 위 이메일로 요청하면 본인 확인 후 가능한 범위에서 처리합니다. 본인 확인을 위해 신청에 사용한 SOOP 아이디나 신청 시점 등 최소 정보 확인을 요청할 수 있습니다.

브라우저에만 저장된 주소·작성글은 운영자가 열람할 수 없습니다. 해당 정보의 수정·삭제는 브라우저 저장 데이터 삭제 또는 페이지 안의 주소 초기화 기능으로 직접 처리해 주세요. 통계는 일별 집계 형태라 특정 방문자의 기록만 분리해 찾거나 삭제할 수 없습니다.

6. 자동 수집 및 쿠키

페이지 자체는 광고 쿠키나 제3자 웹 분석 SDK를 사용하지 않습니다. 브라우저 localStorage를 개인 설정 보관에 사용합니다. Firebase Authentication의 익명 로그인은 광고 신청을 접수할 때만 사용되며, Firebase가 인증 상태를 유지하기 위해 브라우저 저장소를 사용할 수 있습니다. GitHub, Google, SOOP 등 외부 제공자가 운영상 쿠키나 접속 로그를 처리할 수 있습니다.

7. 안전성 확보와 공개 정보

서버는 요청량을 제한하고, 통계에 IP 원문·검색어·계정 ID를 기록하지 않으며, 링크 키를 해시해 집계합니다. 다만 공개 페이지에 표시되는 닉네임·SOOP 아이디와 이용자가 직접 입력하거나 외부 사이트로 이동하는 정보의 복제·촬영·수집을 완전히 막을 수는 없습니다. 공개 목록의 비밀성이나 완전한 복사 방지를 보장하지 않습니다.
