# admin-center

## 공개 홍보 게시판 링크 페이지 만들기

공개 홍보 링크 페이지는 스트리머별 뻐꾸기·콘텐츠 추천·게임 추천 게시판 링크를 담은 단독 HTML입니다. 기준 목록은 생성 시점의 서버 데이터 스냅샷이며, 방문자가 수정한 주소와 홍보글 초안은 각자의 브라우저 `localStorage`에만 저장됩니다.

관리자가 서버 목록을 갱신해 배포하려면 Firebase CLI에서 관리자 계정으로 로그인한 뒤 저장소 루트에서 실행합니다.

```sh
node scripts/build-public-promo-links.js
```

이 명령은 무작위 128비트 버전 ID를 만들고 `releases/<버전>.html`에 새 페이지를, `public-promo-latest.json`에 최신 버전 포인터를 생성합니다. `releases/<버전>.html` 링크를 관리자 방송국 게시판에 게시해 배포하세요. 이전 버전은 열릴 때마다 최신 포인터를 확인하고, 오래됐거나 확인에 실패하면 사용을 잠근 뒤 관리자 방송국으로 안내합니다. 따라서 버전 확인에는 인터넷 연결이 필요합니다. 공개 페이지는 정적 클라이언트이므로 기술적으로 소스 코드를 직접 수정해 검사를 우회하는 것까지 방지하는 DRM은 아닙니다.

`public-promo-links.html`은 최신 배포본의 로컬 미리보기용 사본입니다. 사용자에게는 추측하기 어려운 주소가 생성되는 `releases/<버전>.html` 링크를 공유하세요. 사용자별 주소 수정이나 홍보글 초안은 페이지의 `백업`/`복원`으로 옮길 수 있습니다.
