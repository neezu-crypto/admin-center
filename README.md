# admin-center

## 공개 홍보 게시판 링크 페이지 만들기

공개 홍보 링크 페이지는 스트리머별 뻐꾸기·콘텐츠 추천·게임 추천 게시판 링크를 제공하는 독립 HTML입니다. 닉네임과 SOOP 아이디는 서버에서 30개 단위로 조회하며, 방문자가 수정한 주소와 홍보글 초안은 각자의 브라우저 `localStorage`에만 저장됩니다.

관리자가 서버 목록을 갱신해 배포하려면 Firebase CLI에서 관리자 계정으로 로그인한 뒤 저장소 루트에서 실행합니다.

```sh
node scripts/build-public-promo-links.js
```

이 명령은 무작위 128비트 버전 ID를 만들고 `releases/<버전>.html`에 새 페이지를, `public-promo-latest.json`에 게시 준비 정보를 생성합니다. HTML에는 전체 목록이나 글쓰기 주소·resolver 토큰을 넣지 않습니다. 공개 목록 API는 페이지당 최대 30개를 반환하고 IP별 시간당 요청 수를 제한하며, 각 글쓰기 주소도 별도의 IP별 요청 제한을 거친 뒤 서버가 리다이렉트합니다. 이는 자동 대량 수집을 늦추는 조치이지, 누구나 볼 수 있는 닉네임·아이디를 복사하지 못하게 하는 완전한 접근 통제는 아닙니다. 주소 매핑과 목록 스냅샷은 공개 저장소 밖 임시 파일(권한 0600)에 보관됩니다. 이전 정적 페이지 파일은 URL을 제거한 업데이트 안내 페이지로 바꿉니다. `releases/<버전>.html` 링크를 관리자 방송국 게시판에 게시해 배포하세요. 실제 목적지는 링크를 열면 브라우저 주소창과 개발자 도구에서 확인할 수 있습니다.

새 HTML을 Pages에 배포하고 관리자 방송국에 게시한 다음, 서버에서 허용할 버전을 게시글 주소와 함께 활성화합니다.

```sh
node scripts/activate-public-promo-version.js 'https://www.sooplive.com/station/skftodwocks2/post/게시글번호'
```

현재 게시글이 아직 없다면 게시판 주소를 임시 안내 주소로 사용할 수 있습니다. 활성화된 버전은 Cloud Function이 30초마다, 글쓰기 주소 열기·홍보글 복사 등 주요 동작 직전에 확인합니다. 구버전과 확인 불가 상태에서는 기능을 잠급니다. 활성화가 성공하면 서버에서 이전 버전의 목록과 주소 매핑을 정리합니다.

고정 경로인 `public-promo-links.html`은 구버전 사용을 막는 안내용 진입점이며 항상 잠겨 있습니다. 사용자에게는 추측하기 어려운 주소가 생성되는 `releases/<버전>.html` 링크만 관리자 방송국 게시글에 공유하세요. 사용자별 주소 수정이나 홍보글 초안은 페이지의 `백업`/`복원`으로 옮길 수 있습니다.
