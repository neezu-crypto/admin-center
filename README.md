# admin-center

## 공개 홍보 게시판 링크 페이지 만들기

`public-promo-links.html`은 스트리머별 뻐꾸기·콘텐츠 추천·게임 추천 게시판 링크를 담은 단독 HTML 페이지입니다. 기준 목록은 생성 당시 서버 데이터를 담은 스냅샷이며, 방문자가 수정한 주소와 홍보글 초안은 각자의 브라우저 `localStorage`에만 저장됩니다. 방문자 간 설정은 공유되지 않습니다.

관리자가 서버 목록을 갱신해 배포하려면 Firebase CLI에서 관리자 계정으로 로그인한 뒤 저장소 루트에서 실행합니다.

```sh
node scripts/build-public-promo-links.js
```

이 명령은 `public-promo-links.html`을 새 기준 목록으로 다시 생성합니다. 생성된 HTML을 관리자 방송국에 새 버전으로 올려 공유해야 이용자에게 변경된 기준 목록이 전달됩니다. 이미 다운로드한 파일은 자동 갱신되지 않습니다. 이용자별 주소 수정이나 홍보글 초안은 페이지의 `백업`/`복원`으로 옮길 수 있습니다.
